# Highlands Borough Floodmapper

Generated from the Avalon template using town-specific gauges, datum offsets, thresholds, overlay roots, and the hard-coded municipal boundary from Towns.shp.

Flood rasters are generated by the portable North Wildwood connectivity pipeline: bounded-cubic one-foot terrain, automatic shared-side source qualification, minimax first-connection stages, five tidal phase families, developed-land attenuation, public-road-only visible feeders, five-foot pooling, and stepped depth classes. Highlands retains its existing colors and its 0.00/0.00/0.00-foot minor/moderate/major attenuation anchors. No separate site-specific bulkhead crest was supplied, so no North Wildwood crest elevation is borrowed.

## Modern Highlands controls

The desktop cards and mobile control drawer share Forecast/Past, Lower end/Mean/Upper end, Choose date, opacity with percentage, and discrete flood-stage bands with uncertainty. Hourly and 15-Min replay are joined by Daily Max, which selects the highest available water level per New York day and retains its timestamp and hydraulic phase. Past Daily Max shows the selected day; use date arrows to move between days. Partial days use the available readings only. This is a peak-water-level frame, not a per-cell maximum-depth composite.

Satellite imagery is available in the live map and PNG/GIF exports. The Highlands-specific guided tour supports the mobile drawer, keyboard focus, and Escape. Interval help explains sampling and data gaps.

North Wildwood's modeled return-period floods, road/structural impacts, parcel inspection, and 3D controls are not enabled: Highlands has no corresponding configured local datasets in this repository. They require Highlands data and validation before being exposed in the UI.
